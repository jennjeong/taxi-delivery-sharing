# 택시·배달 합승 모집 및 참여 웹 서비스

기숙사와 학교 주변에서 택시비나 배달비를 나누려는 학생은 많지만, 현재는 단체 채팅방이나 커뮤니티 게시글을 통해 인원을 모집하고 있어 정원 초과, 출발 시간이 지난 모집에 대한 연락, 참여 확정 여부의 혼선 등의 문제가 반복되고 있다.

본 과제는 학생들이 택시·배달 합승 인원을 모집하고, 정원과 시간에 따른 참여 규칙을 시스템이 자동으로 관리하는 교내 웹 서비스를 Spring Boot 기반으로 개발하는 것을 목표로 한다.
학생은 모집글을 작성하거나 모집 중인 글에 참여를 신청할 수 있으며, 정원 초과, 출발 시간 경과, 본인 모집글 참여, 중복 참여 등의 조건은 서버에서 자동으로 검증하여 차단한다.
이를 통해 합승 모집 및 참여 과정에서 발생하는 혼선을 줄이고, 학생들의 교통비와 배달비 부담을 낮추는 것을 목표로 한다.


최신자 반영 목록, (10.28일)

1. 기존 사용자 DB 구조 및 마이그레이션 검토
- 기존 사용자 엔티티와 테이블 구조 확인
- 기존 데이터와 신규 스키마 간 호환성 검토
- 데이터 마이그레이션 적용 절차 및 주의 사항 정리

2. MySQL 8.4 연결 및 데이터 정합성 검증
- 애플리케이션과 데이터베이스 간 연결 상태 확인
- 주요 사용자 데이터 조회 및 저장 테스트
- 필수 필드, 고유 제약조건, 데이터 중복 여부 검증

3. 사용자 인증 및 권한 검증
- 로그인 및 로그아웃 처리 흐름 점검
- 로그인 상태에 따른 API 접근 권한 확인
- 비로그인 사용자 및 권한이 없는 사용자의 접근 제한 검증

4. 세션 및 예외 상황 테스트
- 로그인 시 세션 갱신 여부 확인
- 로그아웃 이후 세션 무효화 검증
- 잘못된 인증 정보 및 만료된 세션에 대한 예외 처리 확인

주요 산출물: DB 마이그레이션 검토 기록, 데이터 정합성 테스트 결과, 인증·권한 검증 결과
